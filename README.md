# NORTEMS // SYSTEM 84

Вторая версия нового визуального стиля по референсу пользователя.

- CRT/scanlines/noise
- чёрно-зелёная терминальная эстетика
- боковая панель быстрых действий
- открывающееся меню
- адаптивная мобильная версия
- небольшая интерактивность кнопок
- рабочая форма заявки и Vercel API сохранены

Загрузите содержимое папки в корень GitHub-репозитория.


## V2 правки
- Кнопка с тремя полосками открывает главное меню.
- Заголовок: «Аут-Лайн».
- SVG-иконки TikTok / YouTube / Discord в стиле терминала.
- Подписи быстрых кнопок на русском.
- Тема переключается между белым на чёрном и чёрным на белом.
