# NORTEMS // SYSTEM 84

Вторая версия нового визуального стиля по референсу пользователя.

- CRT/scanlines/noise
- чёрно-зелёная терминальная эстетика
- боковая панель быстрых действий
- открывающееся меню
- адаптивная мобильная версия
- небольшая интерактивность кнопок
- рабочая форма заявки и Vercel API сохранены

Загрузите содержимое папки в корень GitHub-репозитория.


## V2 правки
- Кнопка с тремя полосками открывает главное меню.
- Заголовок: «Аут-Лайн».
- SVG-иконки TikTok / YouTube / Discord в стиле терминала.
- Подписи быстрых кнопок на русском.
- Тема переключается между белым на чёрном и чёрным на белом.

## V3
- Четыре темы по кругу: зелёная → голубая → красная → жёлтая.
- Системные кнопки и социальные сети перенесены в меню ☰.
- В описании используется название «Аут-Лайн».
- В архив добавлена история перехода со старой версии на новую.

## V4
- Возвращено постоянно отображаемое боковое меню быстрых действий.
- Кнопка ☰ по-прежнему открывает расширенное меню.

## V5
- Архив переведён в простую нумерованную историю 1 / 2 / 3 без карточек-рамок.
- Убран блок «Северный статус».
- Кнопка «Язык» открывает выбор: English, 中文, Русский, Українська, 日本語.
- Возвращены стилизованные SVG-иконки TikTok, YouTube и Discord.
- Социальные кнопки открывают заданные ссылки.
- Discord-ссылка оставлена как будущая точка входа; доступ к Discord после авторизации будет добавлен позже.

## V6
- Дизайн не изменён.
- Язык переключает весь размеченный интерфейс между English / 中文 / Русский / Українська / 日本語.
- Выбранный язык сохраняется в браузере.
- YouTube и TikTok ведут напрямую на каналы владельца.

## V7
- YouTube и TikTok используют прямую навигацию на обновлённые ссылки.
- Перевод выполняется для всех текстовых узлов интерфейса, включая описание, регистрацию, архив, меню, кнопки и подписи.
- Язык сохраняется и применяется после перезагрузки страницы.

## V8
- Исправлены дублирующиеся обработчики TikTok/YouTube, из-за которых поздние функции перезаписывали рабочие ссылки.
- TikTok и YouTube теперь используют прямой `window.location.href` на заданные адреса.
- Перевод переведён на стабильные ключи для всех видимых текстов страницы, включая описание, меню, системную карточку, блок участников, архив, анкету, placeholders и окно выбора языка.
- Добавлено стилизованное окно успешной подачи анкеты с CRT-эффектом, неоновым знаком ✓, статусом TRANSMISSION COMPLETE и кнопкой возврата.
- Окно успеха также полностью переводится выбранным языком.
